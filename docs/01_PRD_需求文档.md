# 🚀 JellyPlayer v2.0 进阶开发需求文档 (PRD)

## 📌 一、 文档概述与战略目标

本需求文档针对 JellyPlayer 当前版本（v1.0）中尚未开发或仅实现骨架的进阶功能，梳理并规划了下一阶段（v2.0）的迭代路径。
**核心战略建议**：采用**“先内后外，先单机后联机”**的迭代策略。即首先彻底打通单人观影的极致体验（播放器内核深度强化），随后完善 UI 层面的高级定制能力，最后攻克技术难度最高的实时多人协同（SyncPlay）与离线下载引擎。

---

## 🎯 二、 阶段一：播放器内核深度强化 (最高优先级)
*此阶段直接决定了作为一款“播放器”的核心专业程度，建议投入核心精力优先攻坚。*

### 1.1 多音轨与多字幕热切换
- **功能描述**：在视频播放过程中，允许用户无缝切换不同的语言音轨（如国语/英语）和字幕流（如内嵌 PGS / 外挂 SRT）。
- **技术指引**：
  - 前端 UI 已经就绪。需深入 `hls.js` 实例 API，调用 `hls.audioTracks` 和 `hls.subtitleTracks`。
  - 遇到 Direct Play 模式时，需对接原生的 `<video>` 标签 `textTracks` API。
- **验收标准**：切换音轨/字幕时不中断当前视频缓冲，切换响应时间 < 1s。

### 1.2 时间轴悬浮预览 (BIF Thumbnails)
- **功能描述**：当鼠标悬停在底部进度条时，上方弹出对应时间点的视频画面缩略图。
- **技术指引**：
  - 依赖 Jellyfin 的 BIF (Base Index Frame) 缩略图生成功能。
  - 需解析 Jellyfin 返回的 `.bif` 文件或特定的精灵图 (Sprite Sheet)，并根据鼠标坐标计算对应时间戳，裁剪展示。

### 1.3 章节标记与“跳过片头”自动执行
- **功能描述**：进度条上显示章节分割点；支持基于后台插件标记自动跳过片头/片尾。
- **技术指引**：
  - 调用 `GET /Videos/{itemId}/Chapters` 获取章节数组并在进度条上绘制分隔线。
  - 读取 Item 数据中的 `MarkerTicks` (片头/片尾标记)，在播放进度达到该时间点时，UI 浮现“跳过片头”按钮，或根据用户设置自动触发 `video.currentTime = skipTarget`。

## 🎨 三、 阶段二：高度定制化与主题引擎 (中优先级)
*增强软件的用户黏性和个性化表达，技术实现难度中等。*

### 2.1 首页模块拖拽排版 (Drag & Drop)
- **功能描述**：在【设置】->【界面】中，提供可视化界面允许用户上下拖拽调整“继续观看、最新加入、猜你喜欢”等板块的顺序。
- **技术指引**：
  - 引入已经安装好的 `@dnd-kit/core` 与 `@dnd-kit/sortable` 构建拖动列表。
  - 拖拽结束后，将新的排序数组更新到 `useSettingsStore` 的 `homeLayout` 字段，首页会自动完成重绘。

### 2.2 全局 CSS 变量主题引擎
- **功能描述**：完善目前仅处于设计稿阶段的 Ocean（海洋蓝）、Forest（森林绿）等系统级变色主题。
- **技术指引**：
  - 在 `index.css` 中基于 `:root[data-theme="ocean"]` 定义完整的 HSL 颜色映射体系。
  - 将 Zustand 中的 `themeColor` 状态动态绑定到 `<html>` 标签的 `data-theme` 属性上实现秒切。

---

## 🌐 四、 阶段三：SyncPlay 多人实时协同 (高难度)
*极具创新力的社交观影功能，需重构部分架构，建议在核心功能极其稳定后进行。*

### 3.1 强一致性播放控制协议
- **功能描述**：在一个 SyncPlay 房间内，任意成员进行“播放/暂停/快进”操作，全员立刻同步执行，确保观影画面差距在 500ms 以内。
- **技术指引**：
  - 完全依赖 Jellyfin 后端 WebSocket 推送的 `SyncPlayCommand` 指令。
  - 需引入复杂的**延迟补偿算法 (Latency Compensation)**。如果本地时间落后于服务器指定的 `PositionTicks`，需强制执行 `video.currentTime = serverTime` 追平进度。

### 3.2 浮动式实时互动面板
- **功能描述**：播放器右侧边缘支持滑出透明的房间聊天室与用户在线状态列表。
- **验收标准**：弹幕/聊天功能不能遮挡主体字幕，成员头像实时反映加载缓冲状态。

---

## 💾 五、 阶段四：离线沙盒与极客管理 (低优先级/进阶探索)

### 4.1 PWA 离线下载播放
- **功能描述**：用户可点击“下载”，将剧集缓存至浏览器本地，在无任何网络的飞机上离线观看。
- **技术指引**：
  - 使用浏览器的 `Service Worker` 拦截请求，或基于现代浏览器的 `File System Access API` / `IndexedDB` 存储巨大的视频文件数据流。技术极其硬核。

### 4.2 管理员实时控制台
- **功能描述**：在 Admin 大盘中新增“实时服务器日志串流”和“踢出特定在线设备”的操作按钮。
- **技术指引**：
  - 接入 Jellyfin 后端隐藏较深的 `/System/Logs/Log` 与 `/Sessions/Message` 发送系统级别的强制终止指令。

---

## 💎 六、 阶段五：发烧友级顶级特性补全 (对标 Infuse / Plex)
*本章节提炼自业界顶级流媒体播放器（如 Apple 生态的 Infuse），是打造终极完美形态的未来构想。*

### 5.1 极致音视频徽章系统 (Media Info Badges)
- **核心痛点**：发烧友极其看重片源质量，目前的简单标签无法满足其展示“藏品”的心理需求。
- **功能描述**：深度解析视频的 `MediaSources` 数据流。针对 4K、HDR10+、杜比视界 (Dolby Vision)、杜比全景声 (Dolby Atmos)、DTS-HD 等极其专业的音视频规格，提取并在详情页和播放器内部高亮展示铂金质感的专属徽章。

### 5.2 在线字幕即时搜索与下载 (OpenSubtitles 整合)
- **核心痛点**：观看外语片源时，本地服务器往往缺少匹配的字幕。
- **功能描述**：在播放器控制面板中内置一个搜索框，直接对接 OpenSubtitles API 或是调用 Jellyfin 后端的字幕搜索接口。用户可以在不停止播放的情况下，一键搜索、下载并挂载网络字幕。

### 5.3 元数据手动修正与刮削 (Fix Match)
- **核心痛点**：系统自动识别（刮削）的电影封面或信息偶尔会出错，目前只能去后台修改。
- **功能描述**：允许具有权限的用户直接在前端 UI 点击“修正匹配”，弹出一个精美的模态框，输入正确的 TMDB/IMDb ID 或名称后，直接在前端触发重新刮削并实时替换海报封面。

### 5.4 触摸屏手势与快捷键映射网络 (Gesture & Hotkeys)
- **核心痛点**：在平板或触屏本上，精准点击细小的进度条体验较差。
- **功能描述**：
  - **手势引擎**：引入防误触的手势检测，实现屏幕左侧上下滑动调亮度（基于滤镜），右侧上下滑动调音量，双击两侧快进/快退。
  - **键盘快捷键**：构建类似 YouTube 的全套快捷键映射（J/L 跳跃，M 静音，F 全屏，空格暂停）。

### 5.5 Trakt.tv 观影记录双向同步
- **核心痛点**：用户如果更换服务器，或者同时使用多个影音平台，观影记录会丢失割裂。
- **功能描述**：在设置中心集成 Trakt.tv 的 OAuth 授权。不仅依赖 Jellyfin 本身的记录，还将用户的每一次播放完成记录异步上报至 Trakt 平台，实现真正的去中心化云端同步。

### 5.6 多服务器统一聚合 (Multi-Server Aggregation)
- **核心痛点**：用户可能同时拥有主服务器、网盘挂载服务器、或者朋友分享的服务器。
- **功能描述**：彻底重构底层状态流，允许用户登录并保存多个 Jellyfin/Emby 实例。将所有服务器的“最新加入”和“继续观看”融合在同一个首页流中，真正做到宛如本地原生 App（如 Infuse）般的“无缝聚合库”体验。

---

> [!TIP] 开发小结
> 针对下个版本，最快能出成果且用户感知最明显的是 **阶段二（主题与拖拽排版）**；而最能凸显项目技术深度的则是 **阶段一（播放器底层剖析）**。如果您有志于打造惊艳开源界的极品软件，**阶段五（特别是发烧友徽章与聚合搜索）** 将是拉开与普通第三方 Web 客户端差距的绝杀武器。
