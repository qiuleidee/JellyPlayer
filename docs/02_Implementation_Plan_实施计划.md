# JellyPlayer v2.0 终极进化实施计划 🚀

基于我们在 v1.0 中取得的巨大成功，本计划旨在将 JellyPlayer 从一个“好用的 Web 客户端”推升至“发烧友级别的极致家庭影院中心”。本次 2.0 计划完全对标 Infuse、Apple TV 等顶级流媒体软件的体验标准。

## 📅 核心开发阶段划分

### 阶段一：发烧友级视听徽章系统 (Media Info Badges)
- **目标**：彰显高规格片源的价值，满足影音发烧友的展示需求。
- **任务**：
  - 深度解析视频 `MediaSources` 数据。
  - 提取并设计专属的铂金/渐变质感徽章：4K HDR, 杜比视界 (Dolby Vision), 杜比全景声 (Dolby Atmos), DTS-HD。
  - 在详情页 (DetailPage) 和播放器内部信息流中全局高亮展示这些徽章。

### 阶段二：播放器内核极客进阶 (Player Pro Features)
- **目标**：彻底打通高级播放控制体验。
- **任务**：
  - **多音轨与多字幕热切**：深入对接 `hls.js` API，允许在不中断播放的情况下无缝切换内置多语言音轨和字幕轨道。
  - **章节标记 (Chapters)**：在进度条上绘制章节分割点。
  - **跳过片头 (Skip Intro)**：解析媒体的标记时间戳，在到达对应时间点时弹出半透明的“跳过片头”悬浮按钮。

### 阶段三：高度个性化与动态主题 (Customization & Themes)
- **目标**：赋予用户彻底定义自己影院的权力。
- **任务**：
  - **首页模块拖拽排版 (Drag & Drop)**：引入 `@dnd-kit`，在设置中心允许用户通过可视化拖拽调整首页各个栏目（最新加入、猜你喜欢、继续观看）的顺序。
  - **动态主题引擎**：全面落实 CSS 变量系统，实装 Ocean (海洋蓝)、Forest (森林绿) 等多套沉浸式深色变种主题，并实现全局一键秒切。

### 阶段四：元数据手动修正与刮削 (Fix Match)
- **目标**：提供完美的强迫症媒体库管理体验。
- **任务**：
  - 允许在前端 UI 直接点击“修正匹配”。
  - 构建精美的搜索模态框，输入正确影片名后直接调用后端 API 触发重新刮削并实时刷新海报封面。

### 阶段五：在线字幕中心 (Subtitles Hub)
- **目标**：解决外语片源的字幕缺失痛点。
- **任务**：
  - 在播放器面板内置网络字幕搜索系统。
  - 无缝对接 Jellyfin 后端或 OpenSubtitles，实现播放中“一键搜索 -> 下载 -> 实时挂载”的全链路字幕加载功能。

### 阶段六：SyncPlay 多人协同与互动 (SyncPlay Ultimate)
- **目标**：实现真正的“异地同屏”观影体验。
- **任务**：
  - 接入复杂的 WebSocket `SyncPlayCommand` 强一致性同步协议，加入防抖与延迟补偿。
  - 构建附带缓冲状态监测的浮动式右侧聊天室面板。

## 🛠 验证与交付标准

### Automated Tests & Type Checking
- 延续 v1.0 标准，每一个阶段完成后必须执行 `npm run build` 确保 TypeScript 类型绝对安全。
- 确保新增的 `@dnd-kit` 拖拽库等第三方依赖完全按需懒加载 (Lazy Load)，不影响首次页面加载速度。

### 视觉与动效检查
- 所有的音视频徽章必须使用纯 CSS / SVG 绘制以确保高分屏清晰度。
- 播放器内的所有新增控制项（如音轨面板、字幕面板、跳过片头按钮）必须带有毛玻璃背景 (Glassmorphism) 且附带 Framer Motion 顺滑进出场动画。
